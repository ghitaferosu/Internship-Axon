event-service — feeding job UI

POST /admin/venues — { address, script }. Script is the venue DSL: one VENUE "name" line, then one SECTION line per section. Each section needs a compass direction (NORTH/SOUTH/EAST/WEST, one per direction) and a ROWS a..b SEATS a..b range.








  
POST /admin/performers — array of performers, bulk-inserted.

  

  
  

    
  

  







  
POST /admin/events — array of events; each needs an existing venueId and, for every
  performer appearance, an existing performerId with endHour after startHour.
  Events are always created with status DRAFT.
